# Tap Coin Clicker Game

A lightweight browser-based clicker game where you tap a coin to earn currency and buy quant multiplier upgrades.

## Overview

This project is a simple HTML, CSS, and JavaScript game inspired by idle/clicker mechanics. Players earn coins by tapping a central button, then spend coins to increase their quant multiplier for faster progression.

## Features

- Tap-to-earn coin mechanic
- Quant multiplier upgrade system
- Increasing upgrade cost scaling
- Responsive single-page game UI
- No dependencies or build step required

## How to Play

1. Open `index.html` in a browser.
2. Click the `TAP COIN!` button to earn coins.
3. Use the shop upgrade to increase your quant multiplier.
4. Continue upgrading to grow your total coin count faster.

## Local Run

Because this is a static web app, you can either:

- Open `index.html` directly in your browser, or
- Run a local server from the project folder with:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
